# LangGraph-Code

Preconfigured Python Project for building agentic workflows with LangGraph — will boost your productivity and improve your workflow.

## Technology Stack & Dependencies

- Python 3
- virtualenv (.venv)
- pip (Python package installer)
- LangGraph / LangChain
- OpenAI / Groq / Google GenAI / LiteLLM providers
- Pydantic, Pandas

## Getting Started

### 1. Clone/Download the Repository

### 2. Create and activate the virtual environment
```
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies
```
python -m pip install -r requirements.txt
```

### 4. Run the project
```
python main.py
```
